# Medyko (MVP)

Medyko is a healthcare SaaS platform designed to help doctors manage appointments and communicate with patients using AI-powered tools.

The platform integrates scheduling, WhatsApp communication, and automated reminders to simplify clinic operations and reduce missed appointments.

Core features:

- appointment scheduling
- patient notifications
- AI-powered WhatsApp assistant
- appointment reminders
- cancellation and rescheduling workflows
- medical directory for doctors

Tech stack (current MVP):

- React
- Firebase / Firestore
- Python backend services
- WhatsApp API integrations

Status:

This project is currently **in active development** and represents an early MVP.
